### 安装步骤（可复用）

```sh
sudo apt-get install -y build-essential cmake ninja-build pkg-config \
    libsdl2-dev libegl-dev libgl-dev extra-cmake-modules \
    qt6-base-dev qt6-multimedia-dev libqt6svg6-dev \
    qt6-base-private-dev \
    libarchive-dev libzstd-dev libfaad-dev libenet-dev

# Node 20（不通过 apt，避免 12.x）
curl -fL -o node.tar.xz https://nodejs.org/dist/v20.18.0/node-v20.18.0-linux-x64.tar.xz
tar -xf node.tar.xz && mv node-v20.18.0-linux-x64 node

# 平台
tar -xzf mm3server.tar.gz            # 里面是 MM3-Server/
cd MM3-Server/platform && npm install --omit=dev

# 模拟器（x86_64 必须自己编，包里带的是 ARM64）
tar -xzf MM3-Server/source/melonDS-src.tar.gz -C ~/MM3R
cd ~/MM3R/melonDS_CHN
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DENABLE_OGLRENDERER=ON
ninja -C build -j16
cp build/melonDS ~/MM3R/MM3-Server/emulator/melonDS
```

> Ubuntu 22.04 的坑：`Screen.cpp` 需要 `qpa/qplatformnativeinterface.h`（装 `qt6-base-private-dev`）；
> CMake 还要 `libarchive-dev libzstd-dev libfaad-dev libenet-dev`。

| 说明 | 这台机器可同时开好几个房间，瓶颈远未到 |
