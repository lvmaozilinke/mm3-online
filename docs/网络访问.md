# 网络访问与公网联机

平台只用一个 TCP 端口（默认 18090，本机开发用 8090）同时承载网页和 WebSocket。
本文说明局域网、IPv6 直连、DDNS、以及更安全的几种公网方案。

---

## 一、局域网访问

1. 服务器放行端口：Windows 防火墙 / Linux `ufw` 都要允许该 TCP 端口
2. 查服务器局域网 IP：`ipconfig`（Windows）或 `ip -4 addr`（Linux）
3. 浏览器打开 `http://<局域网IP>:<端口>/`

Windows 放行示例（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "MM3 8090" -Direction Inbound -Protocol TCP -LocalPort 8090 -Action Allow
```

Linux：

```sh
sudo ufw allow 8090/tcp
```

## 二、IPv6 直连（公网访问最简单的方式）

中国电信/联通/移动的家宽基本都有公网 IPv6，**不需要端口映射**，只要路由器放行入站即可。

### 1. 确认服务器有公网 IPv6

```powershell
ipconfig                     # 看 "以太网适配器" 下的 IPv6 地址
Get-NetIPAddress -AddressFamily IPv6 | Format-Table IPAddress,PrefixOrigin,SuffixOrigin,ValidLifetime
```

重点关注两个字段：

| 字段 | 含义 | 怎么选 |
| --- | --- | --- |
| `SuffixOrigin=Link` | 后缀由网卡决定，前缀不变就一直是它 | **推荐用这个地址发链接** |
| `SuffixOrigin=Random` | 临时隐私地址，Windows 约 11 小时换一次 | 不要用 |
| `PrefixOrigin=RouterAdvertisement` | 前缀由路由器下发 | 光猫重启/换网可能变，需要 DDNS |

### 2. 访问地址格式

IPv6 在 URL 里**必须加方括号**：

```
http://[240e:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx]:8090/
```

### 3. 确认服务在监听 IPv6

Node 默认监听 `::`（双栈）。本机自测：

```powershell
curl.exe -g "http://[::1]:8090/api/config"
curl.exe -g "http://[240e:...]:8090/api/config"
```

两条都返回 JSON 说明服务端没问题，剩下的是防火墙/路由器。

### 4. 常见阻塞

1. **光猫 / 路由器的 IPv6 防火墙**：多数家用光猫默认开启，会丢弃所有入站连接。
   登录网关（常见 `192.168.1.1`）→ IPv6 设置 → 关闭 IPv6 防火墙，或给该地址的 TCP 端口加放行规则。
2. **运营商封禁**：极少数地区封 80/443，换高端口（如 8090、18090）即可。
3. **客户端没有 IPv6**：手机蜂窝网络一般有；公司/校园网常常只有 IPv4。
   用 <https://test-ipv6.com/> 自查。
4. **VPN / 代理软件**：Clash、V2Ray 等 TUN 模式（`vgate0` 之类的虚拟网卡）可能改变路由，
   排查时先退出这类软件。

### 5. 从外网测试

```powershell
# 任意一台有 IPv6 的电脑/手机热点
curl.exe -g -m 5 "http://[240e:...]:8090/api/config"
```

或用手机浏览器直接打开带方括号的地址。

## 三、地址会变：用 DDNS（AAAA 记录）

家宽 IPv6 前缀由运营商下发，光猫重启后可能变化，需要把域名指向新的地址。

- **DuckDNS**：免费，支持 AAAA；`https://www.duckdns.org/update?domains=<域>&token=<token>&ipv6=<地址>`
- **Cloudflare**：用自己的域名，API 更新 AAAA 记录

Windows 上可以写一个 PowerShell 脚本 + 计划任务（每 5 分钟）：

```powershell
$ip = (Get-NetIPAddress -AddressFamily IPv6 -InterfaceAlias '网线' |
       Where-Object { $_.SuffixOrigin -eq 'Link' -and $_.IPAddress -notlike 'fe80*' } |
       Select-Object -First 1).IPAddress
if ($ip) {
  Invoke-RestMethod "https://www.duckdns.org/update?domains=你的域名&token=你的token&ipv6=$ip" | Out-Null
}
```

之后就可以用 `http://[你的域名]:8090/` 访问。

## 四、没有公网 IPv6 时的替代方案

| 方案 | 适用 | 说明 |
| --- | --- | --- |
| **Tailscale / ZeroTier** | 双方装客户端 | 走 NAT 穿透，不受 CGNAT 影响，最省心；缺点是对方也要装 |
| **frp** | 有公网 VPS | 服务器主动连 VPS，VPS 暴露端口 |
| **Cloudflare Tunnel** | 有域名 | 无需公网 IP，自带 HTTPS 和访问策略 |
| **IPv4 端口映射** | 有公网 IPv4 | 现在家宽多数是 CGNAT，通常不可用 |

## 五、安全提醒

把端口直接暴露到公网时：

1. **平台目前没有访问口令**（只有昵称登录），任何人拿到链接都能建房、占满 CPU。
   建议至少开启 `config.ini` 里的访问口令（如果版本支持），或：
2. 用 Tailscale / Cloudflare Access 之类做一层访问控制
3. 不要在公网暴露 8090 的同时把机器上的其他服务也放出去
4. 定期看服务日志，异常建房/长时间无人房间可以手动清理

## 六、端口速查

| 用途 | 端口 |
| --- | --- |
| 网页 + WebSocket | `config.ini` 的 `server.port`（默认 18090） |
| 模拟器宿主控制 | 127.0.0.1:7100~7199（仅本机，不需要对外） |

> 模拟器宿主只绑定 `127.0.0.1`，公网只需要放行一个网页端口。
